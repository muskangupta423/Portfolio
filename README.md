# Muskan Gupta | Portfolio

Static portfolio site (HTML, CSS, vanilla JS). No build step.

- `index.html`: content
- `styles/main.css`: design tokens, dark/light themes, bento layout
- `scripts/main.js`: theme toggle, scroll reveal, count-up stats
- `resume/Muskan_Gupta_Resume_2026.pdf`: linked from the nav

Preview locally: `python3 -m http.server` then open http://localhost:8000
